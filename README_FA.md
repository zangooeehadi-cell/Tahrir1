# HADI — موتور تحریر خواننده
نسخه 0.3 موتور صوتی بازنویسی شده است. موتور تأخیر مدوله‌شدهٔ نسخهٔ قبل با یک تغییر‌دهندهٔ زیروبمی دوهدی با crossfade جایگزین شده و خروجی خشک و پردازش‌شده هم‌تراز زمانی هستند. یک تحلیل‌گر خودهمبستگی نیم‌نرخ برای تشخیص صدای دوره‌ای و فعال‌سازی پس از نگه‌داشتن صدا اضافه شده است.

کنترل‌ها: Auto Tahrir برای میزان افکت، Tahrir Boost برای افزایش عمق، Hold برای زمان نگه‌داشتن، Pitch Depth برای عمق زیروبمی، Speed برای سرعت و Style برای الگوهای اولیهٔ فارسی/عربی/ترکی.

محدودیت‌ها: این نسخه یک موتور DSP آزمایشی و قابل شنیدن است، نه محصول حرفه‌ای نهایی. تحلیل خودهمبستگی فعلاً فقط برای گیت صدای دوره‌ای استفاده می‌شود. تفکیک هوشمند ویبراتو از تحریر طبیعی، تقویت مستقل تحریر موجود، حفظ فرمَنت پیشرفته و مدل‌های استخراج‌شده از خوانندگان واقعی هنوز پیاده‌سازی نشده‌اند. کیفیت و طبیعی‌بودن باید با نمونه‌های واقعی در Cubase آزمایش شود. کامپایل موفق سازگاری با Cubase 5 را تضمین نمی‌کند.
