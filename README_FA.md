# HADI — موتور تحریر خواننده
نسخه 0.4 از Signalsmith Stretch برای تغییر زیروبمی طیفی استفاده می‌کند. این کتابخانه تغییر pitch در جریان صوتی و جبران فرمَنت را پشتیبانی می‌کند و با مجوز MIT منتشر شده است.

موتور HADI از تحلیل خودهمبستگی نیم‌نرخ برای تشخیص صدای دوره‌ای و گیت فعال‌سازی پس از کشیده ماندن نت استفاده می‌کند. الگوهای اولیهٔ تحریر فارسی، عربی و ترکی با کنترل سرعت و عمق به موتور pitch-shift داده می‌شوند. مسیر خشک با تأخیر گزارش‌شدهٔ موتور هم‌تراز می‌شود.

محدودیت‌ها: تفکیک دقیق ویبراتو از تحریر طبیعی و تقویت مستقل تحریر موجود هنوز پیاده‌سازی نشده‌اند. تشخیص F0 فعلاً برای گیت اولیه است و باید روی صدای واقعی ارزیابی شود. الگوهای سبک‌ها طراحی‌شده‌اند و از مجموعه‌دادهٔ خوانندگان استخراج نشده‌اند. تا زمان آزمون شنیداری، این نسخه را محصول حرفه‌ای نهایی ندانید.

کتابخانه‌های Signalsmith Stretch و Signalsmith Linear با مجوز MIT استفاده شده‌اند. منابع: https://github.com/Signalsmith-Audio/signalsmith-stretch و https://github.com/Signalsmith-Audio/linear
