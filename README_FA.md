# Smart Tahrir Processor

پلاگین VST3 برای آزمایش پردازش زندهٔ صدای خواننده، با رابط فارسی‌پذیر و سبک‌های پایهٔ فارسی، عربی و ترکی.

## نسخه 0.2 — موتور آزمایشی اولیه

این نسخه نسبت به اسکلت قبلی پردازش صوتی واقعی دارد:
- ورودی و خروجی استریو
- تشخیص شروع صدای کشیده بر اساس سطح انرژی (نه تشخیص کامل نت)
- فعال‌سازی پس از Hold Time
- ساخت حرکت زیروبمی با خط تأخیر مدوله‌شده و منحنی‌های متفاوت برای سه سبک
- کنترل شدت، عمق، سرعت و زمان نگه‌داشتن
- ذخیره و بازیابی تنظیمات پلاگین
- گزارش تأخیر ثابت پردازش به میزبان (حدود 8 میلی‌ثانیه)

## محدودیت‌های مهم

این نسخه موتور نهایی و حرفه‌ای تحریر نیست. هنوز:
- تشخیص دقیق F0 و گام نت پیاده‌سازی نشده است.
- تفکیک ویبراتو از تحریر واقعی وجود ندارد.
- Enhance هنوز تحریرهای طبیعی خواننده را به‌صورت هوشمند شناسایی و تقویت نمی‌کند؛ کنترل آن شدت عمق افکت تولیدی را تنظیم می‌کند.
- الگوهای سه سبک، الگوهای اولیهٔ DSP هستند و از اجرای خوانندهٔ مرجع یا مدل یادگیری ماشین استخراج نشده‌اند.
- کیفیت طبیعی و نبود آرتیفکت باید با صدای واقعی و بافر/نرخ نمونه‌برداری مختلف آزمایش شود.

این محدودیت‌ها عمداً شفاف نوشته شده‌اند تا نسخهٔ آزمایشی با محصول نهایی اشتباه گرفته نشود.

## Build

GitHub Actions روی شاخهٔ `main.hadi.z` پلاگین Windows x64 VST3 را می‌سازد و به‌صورت Artifact منتشر می‌کند.
