# Smart Tahrir Processor

پروژهٔ ساخت پلاگین VST3 برای پردازش زندهٔ صدای خواننده.

## وضعیت فعلی: Prototype 0.1

این نسخه فقط برای آزمایش زنجیرهٔ ساخت و سازگاری اولیه است:
- پلاگین VST3 با JUCE ساخته می‌شود.
- صدا بدون پردازش از ورودی به خروجی عبور می‌کند.
- پارامترهای اولیهٔ Enhance، Auto Tahrir، Hold Time و Depth در رابط کاربری ذخیره می‌شوند.
- **هنوز هیچ تشخیص زیروبمی، تقویت تحریر یا تولید خودکار تحریر پیاده‌سازی نشده است.**

## ساخت خودکار

با هر Push به شاخهٔ `main.hadi.z` یا اجرای دستی GitHub Actions، فرایند ساخت ویندوز اجرا می‌شود. خروجی در بخش Actions به‌صورت Artifact قرار می‌گیرد.

## نقشهٔ راه فنی

1. تأیید کامپایل و تولید فایل VST3.
2. آزمایش بارگذاری و عبور صدای زنده در میزبان.
3. پیاده‌سازی تشخیص Pitch کم‌تأخیر و تحلیل منحنی Pitch.
4. جداسازی ویبراتو از تحریر.
5. تقویت تحریر واقعی خواننده.
6. تولید کنترل‌شدهٔ تحریر روی نت کشیده با سبک‌های فارسی، عربی و ترکی.

## نکتهٔ سازگاری

ساخته‌شدن VST3 به‌معنای تضمین سازگاری با Cubase 5 نیست. بارگذاری در Cubase 5 باید جداگانه آزمایش شود.
