# HADI — Custom Tahrir Shape
این نسخه سرعت واکنش را با کاهش زمان Hold پیش‌فرض به 140ms، Attack به 8ms، افزایش محدودهٔ سرعت تا 14Hz و کاهش اندازهٔ پنجرهٔ موتور تغییر زیروبمی، سریع‌تر می‌کند.

امکانات جدید:
- رسم منحنی مسیر زیروبمی با ماوس.
- وارد کردن WAV کوتاه و استخراج مسیر F0 با تحلیل autocorrelation؛ الگوی استخراج‌شده به عنوان منحنی نسبی اجرا می‌شود، نه کپی صدای خام.
- انتخاب منحنی سفارشی یا الگوهای داخلی Persian/Arabic/Turkish.

محدودیت مهم: استخراج F0 تک‌صدایی و اولیه است؛ نمونهٔ تمیز و تک‌خواننده لازم دارد. نسخه هنوز تشخیص حرفه‌ای تحریر از ویبراتو، و تقویت مستقل تحریر واقعی خواننده را ندارد. قبل از استفادهٔ اجرایی باید با نمونه‌های واقعی تست شود.
