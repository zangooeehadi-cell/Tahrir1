Smart Tahrir Processor
Version: 0.2 experimental DSP

Implemented:
- JUCE VST3 project
- Generated JuceHeader via juce_generate_juce_header
- Stereo input/output
- Modulated-delay pitch ornament engine
- Sustained input-energy hold gate
- Persian / Arabic / Turkish initial curve profiles
- Enhance, Auto Tahrir, Hold, Depth, Speed, Style controls
- Parameter state persistence
- Reported fixed latency
- Windows x64 GitHub Actions build and artifact upload

Not yet implemented:
- Reliable monophonic F0 tracking
- Vibrato versus tahrir classification
- Smart enhancement of a singer's existing tahrir
- Musical phrase-level ornament generation / microtonal scale adaptation
- Final quality and host compatibility validation

This is an experimental audible DSP build, not a production-ready vocal processor.
